   ```
   eq: rho*(diff(u,t) + u*diff(u,x)) = -diff(p,x) + mu*diff(u,x,2) + f_thermal;
   sol: ode2(eq, u, x);
   /* トルク平衡式 */
   torque_balance: integrate(r * cross(F_thermal, r), r, 0, R);
   ```

### **フェーズ1：基盤AI（5モジュール以内で完結するもの）**

1. **VF‑AI‑04‑M1**：化学反応の熱力学計算（Maxima単独）

3. **VF‑AI‑02‑M1**：増殖微分方程式の一般解（Maxima）

### **フェーズ2：連成実証（Maxima → Python 連成）**

4. **VF‑AI‑01‑M1 → M3**：基礎式導出 → 初期条件生成
5. **IS‑AI‑01‑M1 → M3**：航路方程式 → 数値積分

### **フェーズ3：複雑AI（モジュール数が多いもの）**

6. **WH‑AI‑01**（時空計量安定化AI）は最後に。
