# PAI-18-EXT1 アイスレオロジー（氷クリープ）モデル

## 課題仕様

### 目的

氷クリープ（アイスレオロジー）に基づく摩擦係数 $\mu(T,t)$ をモデル化し、
力 $F = \mu \cdot N$ が目標値 $1000\,\mathrm{N}$ を満たす条件を評価する。

### 数式モデル

#### Glenのクリープ則

$$
\dot{\varepsilon} = A \sigma^n \quad (n=3)
$$

#### アレニウス型温度依存性

$$
A = A_0 \exp\left(-\frac{Q}{RT}\right)
$$

#### 摩擦係数モデル

$$
\mu(T,t) = \mu_{\min} + (\mu_0 - \mu_{\min}) \exp(-k \cdot \dot{\varepsilon} \cdot t)
$$

### パラメータ

| パラメータ        | 値                    | 単位        | 説明       |
| ------------ | -------------------- | --------- | -------- |
| $\mu_0$      | 0.50                 | -         | 初期摩擦係数   |
| $\mu_{\min}$ | 0.05                 | -         | 最小摩擦係数   |
| $Q$          | 78000                | J/mol     | 活性化エネルギー |
| $A_0$        | $1.0 \times 10^{-8}$ | 1/s       | 頻度因子     |
| $n$          | 3.0                  | -         | Glen則指数  |
| $R$          | 8.314                | J/(mol·K) | 気体定数     |

## 結論

- **総ケース数**: 900
- **目標達成率**: 100.0% (900/900)
- **最良条件**: T=223.2K (-50.0°C), t=0.0h → μ=0.5000
- **最悪条件**: T=223.2K (-50.0°C), t=0.0h → μ=0.5000

### 物理的考察

1. **温度効果**: 低温（-50°C付近）ではクリープが抑制され、高い摩擦係数を維持
2. **時間効果**: 長時間の負荷でクリープが進行し、摩擦係数が低下
3. **応力効果**: 高応力下ではクリープが促進され、摩擦係数低下が加速
4. **Glen則**: 氷のクリープは応力の3乗に比例する非線形挙動を示す

### 設計推奨

- 目標力1000N達成には $\mu \ge 0.25$ が必要
- 低温環境（-30°C以下）かつ短期間（1時間未満）が有利
- 高温や長時間ではクリープによるμ低下を考慮した安全率が必要
