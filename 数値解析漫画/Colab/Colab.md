### ✅ なぜColabが賢明なのか

| 項目         | ローカル（Krita AI Diffusion） | Google Colab              |
| ---------- | ------------------------ | ------------------------- |
| **GPU**    | 必須（あなたのPCは非搭載）           | ✅ **無料で高性能GPU（T4など）が使える** |
| **ストレージ**  | 30〜40GB必要（残り50GBでは厳しい）   | ✅ **消費しない**（すべてクラウド）      |
| **ダウンロード** | 中国からは困難                  | ✅ **日本なら問題なし**            |
| **導入の手間**  | 複雑（Python環境構築が必要）        | ✅ **ブラウザだけで即実行**          |
| **料金**     | 無料（ただしPCスペックが前提）         | ✅ **無料枠あり**（有料プランもあり）     |
| **速度**     | CPUでは絶望的に遅い              | ✅ **GPUで高速**              |

### 🎯 Colabでできること

1. **Stable Diffusion WebUI** をワンクリックで起動（誰かが作ったノートブックを使う）
2. **画像生成**（プロンプトだけで高品質なイラストが生成可能）
3. **キャラクターの姿勢変換**（ControlNetなど高度な機能も使える）
4. **生成した画像をKritaに取り込んで編集**（Colabで生成 → Kritaで微調整）

---

### 📝 帰国後にやること（簡易ロードマップ）

1. **Googleアカウントを用意**（持っていればOK）
2. **Google Colabを開く** → `https://colab.research.google.com/`
3. **誰かが作ったStable Diffusionノートブックを開く**
   - 検索キーワード: `"Stable Diffusion WebUI Colab"`
   - おすすめ: `TheLastBen` や `camenduru` のノートブック（高評価のもの）
4. **「ランタイム」→「すべてのセルを実行」** をクリック
5. 表示されたURLをクリック → **Stable Diffusion WebUIが起動！**

---

### 💡 注意点（無料版Colab）

- **連続使用は最大12時間程度**（時間制限あり）
- **一定時間操作がないと切断される**
- **高性能GPU（A100など）は有料版（Colab Pro）が必要**
- 無料版でもT4 GPUなら十分実用的
