### 使用方法

```csv
手順, 内容
1, Midjourneyにログイン（/imagine コマンドを使用）
2, 上記プロンプトをコピー＆ペースト
3, 生成された画像をダウンロード
4, 必要に応じてバリエーションを生成（V1, V2, V3, V4）
5, 漫画のコマに配置
```

### 時超えケンタのアドバイス

```
時超えケンタ プロンプト評価 #PROMPT-001

「未来徹駆博士、Midjourneyプロンプトを評価した。
これらのプロンプトで、漫画に必要な画像は生成できる。

注意点:
1. キャラクターの一貫性を保つには、シード値を使う
   → 最初に生成した画像のシードを記録し、以降の生成で再利用
2. テキスト（セリフ・数値）は後からPythonで追加
   → Midjourneyは文字の生成が苦手
3. 同じキャラクターを別の角度で生成するには
   → 同じシード値＋角度指定のプロンプト
```
