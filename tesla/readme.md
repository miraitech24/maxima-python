# テスラ型無線送電システム解析

## 課題仕様

### 目的

テスラ型無線送電システムにおける複数ユーザ同時給電時の干渉問題を解析する。

### 数式モデル

#### 回路方程式

$$
\begin{cases}
V = R I_1 + j\omega M_{TA} I_2 + j\omega M_{TB} I_3 \\
0 = j\omega M_{TA} I_1 + (R+Z_L) I_2 + j\omega M_{AB} I_3 \\
0 = j\omega M_{TB} I_1 + j\omega M_{AB} I_2 + (R+Z_L) I_3
\end{cases}
$$

#### 受電電力

$$
P_A = |I_2|^2 Z_L
$$

#### 最適結合条件

$$
M_{opt} = \frac{\sqrt{R(R+Z_L)}}{\omega}
$$

### パラメータ

| パラメータ | 値     | 単位  |
| ----- | ----- | --- |
| 周波数 f | 1.0   | MHz |
| 電圧 V  | 30    | V   |
| 抵抗 R  | 2.0   | Ω   |
| 負荷 ZL | 20    | Ω   |
| M_opt | 1.056 | μH  |
| P_max | 102.3 | W   |

## 結論

### 干渉の影響

| 干渉強度 M_AB | ピーク電力   | ピーク位置 |
| --------- | ------- | ----- |
| 0 μH (なし) | 最大      | M_opt |
| 0.1 μH    | 約70%に低下 | 左へシフト |
| 0.2 μH    | 約40%に低下 | さらに左へ |
| 0.3 μH    | 約20%に低下 | 大きく左へ |

### 強結合域の特性

M_TA > 1.0 μH の強結合域では、全ての曲線が収束する。
これは干渉の影響が相対的に無視できることを意味するが、効率は低下する。

### 結論

> 同時給電では干渉により電力が著しく低下する。
> 実用的な解決策は時分割制御により干渉をゼロにすることである。
