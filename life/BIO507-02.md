# BIO-507-02: Mitochondrial Function Preservation Rate

## 計算方式

- sympyで微分方程式の解析解を導出
- ATP産生: $dA/dt = -kA + r$
- ROS産生: $dR/dt = gR$
- 総合スコア: $S = 0.6 \cdot A/A_0 + 0.4 \cdot (1 - R/R_{\max})$
- Maximaは使用せず

## 数理モデル

$\frac{dA}{dt} = -k \cdot A + r$
$A(t) = \frac{r}{k} + \frac{\left(A_{0} k - r\right) e^{- k t}}{k}$
$\frac{dR}{dt} = g \cdot R$
$R(t) = R_{0} e^{g t}$

## パラメータ

| 記号       | 値          | 説明       |
| -------- | ---------- | -------- |
| $A_0$    | 100.0      | 初期ATP産生量 |
| $R_0$    | 10.0       | 初期ROS産生量 |
| $k$      | 0.015/year | 機能低下率    |
| $r$      | 0.3/year   | 修復率      |
| $g$      | 0.02/year  | ROS増加率   |
| $\alpha$ | 0.4        | 抗酸化能力    |
