- Maxima と Python の連携（ファイルベース連携、強制カップリング禁止）
- Maxima で数式処理・一意解求解・グラフ出力、Python で必要に応じて補完計算
- 対象：惑星間航行（目標距離 40 兆 km = 約 4.23 光年）、巡航速度 0.01c
- 推進方式：反物質推進 (Isp = 1,000,000 s) と 核融合推進 (Isp = 100,000 s) の比較
- 初期質量 m0 = 1×10⁶ kg、Δv 配分：加速 50%・減速 50%
- 計算項目：質量比 MR、燃料質量、必要反物質量など

## 結論

- 核融合推進の燃料質量は約 1.18×10⁶ kg（質量比約 2.18）
- 反物質推進の燃料質量は約 6.73×10⁷ kg（質量比約 68.3）→ 非現実的
- 核融合推進の方が燃料質量が圧倒的に少なく、同条件下では核融合推進が優位
- 反物質推進は比推力が高いが質量比が極端に大きくなり、初期質量に対して燃料が過大
- 本解析から、現実的な恒星間航行には核融合推進の方が実現可能性が高い
