# BIO-507: Aging Suppression Analysis

## 計算方式

- sympyで微分方程式の解析解を導出
- lambdifyでnumpy関数化して数値計算
- Maximaは使用せず

## 数理モデル

$\frac{dT}{dt} = -k \cdot T + r$
$T(t) = \frac{r}{k} + \frac{\left(T_{0} k - r\right) e^{- k t}}{k}$
$P_{\text{sen}}(t) = \begin{cases} \exp\left(-\eta(t) \cdot \frac{T(t) - T_{th}}{T_{th}}\right) & T > T_{th} \\ 1 & T \leq T_{th} \end{cases}$
$\eta(t) = \eta_0 + \alpha \cdot (1 - e^{-t/20})$

## パラメータ

| 記号       | 値         | 説明        |
| -------- | --------- | --------- |
| $T_0$    | 100.0     | 初期テロメア長   |
| $k$      | 0.02/year | 短縮率       |
| $r$      | 0.5/year  | 修復率       |
| $T_{th}$ | 20.0      | 老化閾値      |
| $\eta_0$ | 0.3       | 基本修復効率    |
| $\alpha$ | 0.7       | テロメラーゼ活性化 |
