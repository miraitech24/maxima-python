# BIO-533: Limb Regeneration Probability (Lizard Model)

## 概要

トカゲの四肢再生モデルに基づき、ヒトへの応用可能性と再生確率を計算する。

## 基本パラメータ

| パラメータ   | 値   | 説明             |
| ------- | --- | -------------- |
| ヒト効率因子  | 0.3 | ヒトではトカゲの30%の効率 |
| 免疫抑制効果  | 0.6 | 免疫抑制による再生促進効果  |
| 成長因子活性化 | 0.7 | 成長因子による細胞増殖促進  |
| 瘢痕化防止   | 0.5 | 瘢痕化防止による再生促進   |

| 段階                 | トカゲ成功率     | ヒト換算       |

| Wound Healing      | 0.95 (95%) | 0.28 (28%) |
| Blastema Formation | 0.80 (80%) | 0.24 (24%) |
| Proliferation      | 0.75 (75%) | 0.22 (22%) |
| Differentiation    | 0.70 (70%) | 0.21 (21%) |
| Morphogenesis      | 0.65 (65%) | 0.20 (20%) |

## 数理モデル

$P_{\text{total}} = \prod_{i=1}^{5} P_i$
$P_{\text{age}} = P_0 \cdot e^{-0.02 \cdot \text{age}}$
$P_{\text{size}} = P_0 \cdot e^{-0.5 \cdot \text{size}}$
