## 1. 母船「ヘスペロス」基本仕様 (Ship Specifications)

母船は、単なる移動手段ではなく**「軌道上の拠点工場」兼「司令塔」**として機能します。

- **全長 / 質量**: 約400m / 5,000トン級（ISSの約11倍）。

- **浮力維持システム**:
  
  - 高度50kmの大気密度（地球の1気圧相当）を利用した、巨大な**「ハイブリッド・エアロスタット（飛行船）」**構造。
  
  - 内部には、金星大気から抽出した窒素（N2）と酸素（O2）を充填し、天然の浮力を得ます。

- **電力源**:
  
  - 母船内にも100MW級の常温核融合（LENR）リアクターを2基搭載。
  
  - 地表の「テスラ・グリッド」から送電される電力を受信する大型レシーバー。

- **居住区**:
  
  - 最大50名の技術者・科学者が居住可能。
  
  - 高度50kmは気温約20℃〜50℃、1気圧という、金星で最も地球に近い「快適な」環境です。

## 2. サプライチェーンの核心：軌道上工場 (Orbital Factory)

地球からすべてを運ぶのではなく、**「現地で価値を増大させる」**のがこのプラントの肝です。

- **3Dプリント・ベイ**:
  
  - 金星大気から抽出した炭素を用い、地表用リアクターの「殻（耐圧殻）」を自動製造。
  
  - 1基（10トン級）を約1.12日で出力可能。

- **地球からのサプライ（消耗品）**:
  
  - **触媒・コアユニット**: 日本で製造した「常温核融合の心臓部（格子ユニット）」および精密基板。
  
  - **重水素燃料**: 軌道エレベーターまたはスターシップ級ロケットで定期搬送。

- **デプロイ（配備）システム**:
  
  - 完成したリアクターを母船からマクスウェル山頂へ正確に投下する、自律飛行型エアロシェル。

## 3. 実装ロードマップ：集金と開発の並行処理

前澤氏のようなリーダーが動くための「安・近・短」を強調したフェーズ分けです。

1. **フェーズ1：特許とバーチャル実証 (Year 1-2)**
   
   - 今回の16のプログラム群と特許案を公開。
   
   - 「金星エネルギー債券」の発行とクラウドファンディング（一口1万円から、将来の金星電力の優先受給権を付与）。

2. **フェーズ2：母船「ヘスペロス」建造 (Year 3-5)**
   
   - SpaceXのStarshipを数機連結し、軌道上で母船を組み立て。
   
   - 日本製のLENRユニットを搭載し、金星へ出発。

3. **フェーズ3：マクスウェル山頂開拓 (Year 6-)**
   
   - 最初の「プロト・ベネラ・リボーン」を投下し、100MWの火を灯す。
   
   - そこから自己増殖（15.py）が始まり、10年で「地球の救世主」となります。
