# Venus-Fusion Shuttle Project

金星・地球間を結ぶ高効率輸送シャトルの軌道解析およびテザーシステムの設計ドキュメント。

## 1. 概要

本プロジェクトは、定推力エンジンを搭載したシャトルによる、地球・金星間の高速往還（スプリント・ミッション）の実現を目的とする。テザーシステムによる初期加速支援と、ロケットエンジンの推力最適化により、大幅な航行時間の短縮を目指す。

## 金星輸送：AI無人運用を前提としたテザー耐久性と輸送効率の確定 (Issue #100)

## 1. 物理モデル

フィジカルAIによるリアルタイム損傷監視と自己修復を前提とし、安全率を有人基準（3.0）から無人機標準（1.5〜2.0）へ最適化する。
等断面テザー（断面積 $A$）にかかる最大張力 $T_{max} = a(AL\rho + m_p)$ を算出し、燃料消費に伴う加速度上昇 $a(t)$ の全行程で安全率が 1.5 を下回らないことを検証する。

## 2. 判定基準

- **運用安全率 $S \ge 1.5$**: 無人機（フィジカルAI搭乗）としての工学妥当性を確保。
- **テザー質量 $M \le 100\,\text{kg}$**: $M = \rho A L$。
- **採算性**: 推力を絞らずフルスラスト（最大9.2G）を維持し、14日往還を可能にする。

## 3. 計算手法

- **Maxima**: 与えられた質量制限（100kg）下での「最小安全率 $S$」を代数的に導出。
- **Python**: 燃料消費による船体軽量化（#57）を反映し、ミッション中の $S(t)$ の推移をシミュレーション。

これまでの解析結果（#100 および #101）を統合し、プロジェクトの進捗を `README.md` 形式でまとめました。

### #100: テザーシステム設計 (Tether Analysis)

テザーを用いた初期加速フェーズの安全性を検証。

- **総テザー質量**: 98.60 kg 

- **最小安全係数**: 2.51 

- **ステータス**: **PASS**。構造強度は十分であり、軽量なテザーでの運用が可能。

### #101: 往還軌道解析 (Trajectory Analysis)

金星へのスプリント航行をシミュレーション。

- **Delta-V (加速終了時速度)**: 221.57 km/s 

- **最大加速度**: 8.36 G 

- **総航行日数**: 2.76 日 

- **判定条件**: 14日以内の到達 

- **ステータス**: **PASS**。要件を大幅に上回る速度で到達可能。

## 4. 数値計算モジュール

軌道計算には、Maximaによる解析解をPythonへエクスポートする手法を採用。

### trajectory_params.py (自動生成)

以下の関数により、定推力 $F$ 下での燃料消費に伴う質量変化を考慮した物理量を算出。

- `get_final_v(F, m0, m_dot, t_b)`: 加速フェーズ終了時の速度を算出。 

- `get_final_d(F, m0, m_dot, t_b)`: 加速フェーズ中の移動距離を算出。 

## 5. 実行手順

1. **数式エクスポート**: `shuttle101.mac` を Maxima (batchモード) で実行し、`trajectory_params.py` を生成。

2. **メインシミュレーション**: `shuttle101.py` を実行し、航行日数と安全判定を出力。

## 6. 今後の課題

- **加速度の抑制**: 現在の 8.36 G は有人ミッションとしては過大であるため、推力プロファイルを調整し、3G 程度に抑えた場合の積載重量増加案を検討。

- **燃料効率の最適化**: 航行日数に余裕があるため、比推力の調整による燃料消費の削減。
