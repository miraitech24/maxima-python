# 第2章　金星エネルギー輸出事業

## 1. プロジェクト概要

金星地表のLENR（常温核融合）炉で生成された膨大なエネルギーを、次世代水素ハイドライドとしてパッキングし、地球へ超高速輸送する「惑星間エネルギーサプライチェーン」の構築。

## 2. 輸送・送電メカニズム

本プロジェクトでは、従来の無線送電の減衰問題を克服するため、**「物理カプセル射出方式」**を採用する。

### A. 軌道母船「ヘスペラス (Hesperus)」

- **構造:** 全長5km級のメガストラクチャー。数キロに及ぶ電磁加速レール（レールガン）を背負った宇宙工場。

- **役割:** 地表からのテスラ送電を受電し、カプセルを製造・射出するハブ。

- **仕様:** 居住区は回転リングによる1G環境。3Dプリンターによる自己増殖（#32）機能を備える。

### B. レールガン射出システム

- **制約 (#33):** 3Dプリント筐体および積荷の保護のため、加速度を **50G以下** に制限。

- **初速:** 電圧を **1386.88V** に固定し、精密な電力制御により安定射出を行う。

### C. 使い捨て型核融合エンジンカプセル

- **動力:** カプセル自体に高出力核融合エンジンを搭載。

- **航法 (#48, #57):** 積荷のハイドライドを燃料として消費しながら加速する「可変質量航法」により、14日以内の地球到達を実現。

- **回収方式 (#42):** 地球大気圏突入時はアブレーションにより外殻を消耗。残骸は高純度資源として地球側で回収・売却する（使い捨てによる収益最大化）。

## 4. 経済性評価（暫定ROI：525%）

現在の理論値では、以下の理由により圧倒的な利益率を叩き出している。

1. **エネルギー原価の極小化:** LENRおよび金星資源自給により、発電コストは実質0.01円。

2. **物流回転数の向上:** 往還機の帰還を待たない「撃ちっぱなし」方式によるスループット増。

3. **機体の資源化:** 地球側でカプセル残骸（エンジン含む）を金属資源として売却。
