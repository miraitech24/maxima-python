# 課題32：3Dプリンタ自己増殖の資源収支

## 1. 概要

金星開拓における3Dプリンタの自己複製について、Maximaによる理論的な指数成長率の導出と、Pythonによる資源供給停止時の動的生存シミュレーションを連成して評価する。

### 資源収支シミュレーションの考え方

1. **増殖のルール (Maxima)**:
   金星の資源を使って「自分をコピーする速度」を計算する。
   (例：1ヶ月で10%増える能力がある、という数値を算出)

2. **生存のピンチ (Python)**:
   もし地球からの特殊部品が届かなくなったら、コロニーはどう崩壊するか？
   Maximaが出した「10%」という数字を使って、全滅までのカウントダウンを予測する。

## 2. 解析モデル (Maxima)

増殖の基礎となる微分方程式：
$\frac{dN}{dt} = \alpha N$初期条件 $$N(0) = N_0$ における解析解：
$N(t) = N_0 e^{\alpha t}
※係数 \alpha$ は、金星大気からの炭素回収およびエネルギー効率により一意に決定される。

## 3. 連成（カップリング）仕様

- **出力**: Maximaの `openw` ストリームを用いて、計算された $\alpha, N_0$ を `params.py` に定数定義として書き出す。
- **入力**: Python側で `import params` を実行し、理論値をシミュレーションの基底値として動的に取り込む。
- **回避策**: `with_stdout` によるXMLタグの混入（GUI由来のバグ）を防ぐため、ストリーム出力を採用。

## 4. 動的シミュレーション (Python)

- 補給継続期間 ($t < T_{cutoff}$)：$\alpha = \text{theory\_alpha}$
- 補給停止後 ($t \ge T_{cutoff}$)：$\alpha = -0.1$ (資源枯渇によるシステムダウン)
  この不連続な状況における個体数推移を数値計算する。

提示したグラフは、金星コロニーの**「生死を分ける分岐点」**を視覚化したものです。

具体的に何が起きているのか、3つのポイントで解説します。

### 1. 左側の急上昇：理論上の「お祭り状態」

グラフの左側で数値がグングン上がっている部分は、**Maximaで計算した理想的な増殖**を表しています。

- **意味**: 金星の空気（CO2）から順調に部品を作り、プリンタが「仲間」を増やし続けている状態です。

- **背景**: 1台が2台、2台が4台……と増える「指数関数的成長」のパワーを示しています。

### 2. 赤い点線：運命の「補給停止」

真ん中にある赤い垂直の点線は、**地球からのサポートが切れた瞬間**です。

- **意味**: 3Dプリンタ自体のコピーは金星の材料でできても、精密な基板や特殊な潤滑剤など、「地球からしか来ない重要部品」が届かなくなったことを想定しています。

- **イベント**: ここでシミュレーションの計算ルール（$\alpha$）が「プラス」から「マイナス」に切り替わります。

### 3. 右側の急降下：現実の「サバイバルと崩壊」

点線を境に、グラフが滑り台のように落ちていく部分は、**Pythonが得意とする動的な変化（劣化）**を表しています。

- **意味**: 故障したプリンタを直す部品がなくなり、1台、また1台と動かなくなっていく様子です。

- **結論**: このグラフの「右端」がゼロになるまでの時間が、**「金星コロニーが自力だけで生き残れる限界時間」**ということになります。

### まとめると

このグラフは、**「理論（Maxima）上のイケイケな計画」**が、**「現実（Python）のトラブル」**によってどう壊されるかを1枚にまとめたものです。

- **高い山（ピーク）になればなるほど**: 補給が切れても、残った数が多いので全滅までの「猶予」が稼げる。

- **山の傾斜が急なほど**: 金星での自給自足がまだ不完全で、地球に依存しすぎている。

ということが一目で分かります。
