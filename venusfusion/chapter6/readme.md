# 課題仕様書: #901 水星軌道ハニカム受電パネルの物理限界解析

## 1. 目的

金星のスーパーローテーション（SR）を永続的に制動するためには、外部からの安定した電力供給が不可欠である。水星軌道という超高温・高放射強度環境において、受電パネルが熱的に自壊せず、かつ最大の電力を取り出せる「物理的平衡点」を特定する。

## 2. Maximaで計算する意義

この計算において、Maximaは**「物質の物理限界（熱力学）」**を司る。

Pythonによる面積シミュレーションの前段階として、以下の非線形な物理制約を一意に解く必要がある：

- **熱放射バランス**: $S(1-\eta) = \epsilon \sigma T^4$ という4次方程式を解き、発電効率 $\eta$ とパネル温度 $T$ のトレードオフを数式化する。

- **材料限界の定義**: パネルの耐熱限界 $T_{limit}$ （例：1000K）において、許容される最小の発電効率を導出する。これを疎かにすると、Python側で算出された「面積」が現実には「溶け落ちるパネル」を意味することになる。

- **解析解の提供**: 距離 $r$ に対する必要面積 $A$ の関係を $A \propto r^2$ と単純化する前に、放射冷却効率を含めた**「実効電力密度定数」**を厳密に定義する。

## 3. 連成プロセス

1. **Maxima**: ステファン・ボルツマンの法則を用い、水星平均距離での「受熱・発電・放射」の平衡状態から、単位面積あたりの取り出し可能電力 $W_{unit}$ を算出。これを `params.py` として出力。

2. **Python**: Maximaが保証した $W_{unit}$ をインポートし、水星の離心率に伴う距離変動 $r(\theta)$ を適用して、時系列での必要面積をシミュレートする。
