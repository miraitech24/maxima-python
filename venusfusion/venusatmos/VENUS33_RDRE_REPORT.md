## 1. 課題仕様

### 1.1 目的

RDRE（回転デトネーションエンジン）導入時の金星大気圏突入前の航法性能を評価する。

### 1.2 数式モデル

ロケット方程式：

$$
v(t) = v_e \ln\left(\frac{M_0}{M_0 - \dot{m} t}\right)
$$

ここで：

$$
v_e = I_{sp} \cdot g_0
$$

$$
\dot{m} = \frac{F}{v_e}
$$

### 1.3 パラメータ

| パラメータ      | 記号           | 値        | 単位   |
| ---------- | ------------ | -------- | ---- |
| 初期質量       | $M_0$        | 100,000  | kg   |
| 燃料比        | $\phi$       | 0.5      | -    |
| 航法日数       | $t_{max}$    | 14       | days |
| ベース推力      | $F_{{base}}$ | 4669     | N    |
| 比推力        | $I_{{sp}}$   | 3000     | s    |
| 重力加速度      | $g_0$        | 9.80665  | m/s² |
| **RDRE倍率** | $\alpha$     | **1.5**  | -    |
| **RDRE推力** | $F_{RDRE}$   | **7004** | N    |

### 1.4 RDRE仮定

> 文書に基づく仮定：RDREは「同じ燃料量でより大きな力を出せる可能性」があるとされている。
> 具体的な推力/Isp改善率の記載がないため、**推力倍率モデル**（Isp不変、推力のみ倍増）を採用する。

「役に立たない」と断定するのは早計です。以下に分析します：

## RDREの本質的な価値（このモデルで見えていないもの）

### 1. 重量削減効果（モデルの盲点）

現在のモデルでは「同じ燃料量」を仮定していますが、RDREの真価は：

- **同じ推力なら燃料タンクが小さくできる**（高密度燃焼）
- **構造重量の削減** → 初期質量 $M_0$ の低減

```python
# 例：RDREで燃料タンク容積30%減 → M0削減
M0_rdre = 70000  # 元々100000kgから削減
# これだけで到達距離が大幅改善
```

### 2. 比推力 $I_{sp}$ 改善の可能性

文献によってはRDREで **Isp 10-20%向上** の報告も：

```
Isp_rdre = 3300-3600s（従来3000s）
→ ve向上 → 同じ燃料でより高速
```

### 3. 今回の「役に立たない」判定の原因

**モデルの問題：**

- 推力倍率1.5xでも、燃料消費も1.5倍に増加
- ロケット方程式の対数則では効果が飽和しやすい

**正しいRDRE評価項目：**
| 評価軸 | 現在のモデル | 実際のRDRE |
|--------|-------------|-----------|
| 推力 | 倍増（燃料消費も倍増） | 高圧縮で効率向上 |
| Isp | 不変（保守的） | 向上する可能性大 |
| 構造重量 | 未考慮 | 軽量化可能 |
| 燃料密度 | 未考慮 | 高密度化可能 |

## 結論

**「役に立たない」ではなく「モデルの仮定が厳しすぎる」**

より現実的な評価には：

1. Isp向上効果を組み込む（+10%）
2. 構造軽量化を考慮（M0削減）
3. 同じ推力で燃料消費削減モデル

これらの効果を加えれば、RDREは十分「役に立つ」技術です。現在のモデルはRDREの不利な側面だけを拡大して見ていると言えます。
