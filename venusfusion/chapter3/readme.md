大林組の「宇宙エレベータ建設構想」をベースにする場合、**「空中駅（高度30km）」**は構想内の「地球港（アース・ポート）」と「低軌道駅（LEO）」を繋ぐ動脈の入り口にあたります。

### 1. 空中駅テザーの仕様：大林組構想との比較

基本構造は踏襲しますが、**金星からの「爆速カプセル」を受け止める**ために以下の点が強化・変更されます。

- **素材**: 大林組構想と同じくカーボンナノチューブ（CNT）ですが、カプセルの受領衝撃（#42b）に耐えるため、高度30km付近では**「編み込み（ネット状）」**の衝撃吸収構造になります。

- **役割の拡張**: 大林組構想では「昇降」が主ですが、本プロジェクトでは**「ハイドライドの流下（パイプライン）」**機能が追加されます。

- **高度**: 大林組の地球港は海上に固定されていますが、本プロジェクトの空中駅は**高度30km（成層圏）**で浮遊・維持されるため、テザーの「下端」は海ではなく、そこから降下機が都市へ飛び立つ「空中ハブ」として機能します。

### 2. 航空障害の届け出と法的解決策

高度30kmまで伸びるテザーは、既存の航空路を完全に遮断する「物理的な壁」となります。大林組の構想および本プロジェクトでの想定解決策は以下の通りです。

| **対策項目**            | **具体的な対応内容**                                                         |
| ------------------- | -------------------------------------------------------------------- |
| **航空障害灯**           | テザー全域に高光度航空障害灯を設置。特に雲層（対流圏）付近は多重化する。                                 |
| **排他的飛行禁止区域 (NFZ)** | 空中駅を中心とした半径数十kmを**「恒久的な飛行禁止区域」**として国際民間航空機関（ICAO）に登録する。              |
| **ノータム (NOTAM)**    | 航空情報として常に発給。既存のジェットルート（国際線航路）をテザーを迂回するように再設計・変更届を提出。                 |
| **物理的防御**           | 低高度（10km以下）では、航空機が万が一接触してもテザーを切断せず、航空機側が弾かれる（あるいは検知して自動回避する）システムの構築。 |

> **「大林組は、この巨大な構造物を『建築物』ではなく『恒久的な航路標識』あるいは『新国家インフラ』として定義し、国際合意を取り付ける前提で動いています。」**

### 第3章：計算への影響

この「高度30kmの壁」を前提にすると、次の計算が重要になります。

- **#34a（逆噴射）**: テザーを破壊しないための「相対速度ゼロ」への減速。

- **#53（都市間滑空）**: 航空障害を避けつつ、テザーから各都市へ最短で届ける滑空ルート。
