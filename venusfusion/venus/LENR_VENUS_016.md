スターリングエンジンの変換効率25%という数値は、以下の根拠に基づいています。

## 1. カルノー効率との比較

```
カルノー効率 = 1 - T_cold / T_hot
            = 1 - 298.15 / 623.15
            = 1 - 0.4785
            = 0.5215 → 52.2%
```

理論最大効率52.2%に対し、実機ではその約半分の**25%**が現実的な値です。

## 2. 実機スターリングエンジンの効率実績

| エンジン       | 温度条件     | 実効率     | 備考         |
|:---------- |:-------- |:------- |:---------- |
| 小型スターリング   | 300-600℃ | 20-30%  | 一般的な範囲     |
| 大型スターリング   | 500-800℃ | 30-40%  | 高効率品       |
| 金星条件(350℃) | 350-25℃  | **25%** | 中間温度で控えめ想定 |

## 3. なぜ25%を選んだか

- 熱源350℃はスターリングエンジンにとって**中温域**
- 宇宙用として信頼性重視なら効率を抑えめに設計
- 44kmの熱輸送ロスを見込んで保守的な値を採用
- 中部大学LENRの出力が安定しない可能性を考慮

## 4. もし効率を変えた場合の影響

```
効率20% → 正味出力 約3.2kW
効率25% → 正味出力 約4.5kW（採用値）
効率30% → 正味出力 約5.8kW
```

25%は「過大評価せず、過小評価もしない」バランス点として選んでいます。
