# 課題25：LENR炉の解析における二段階連携の意義

## 1. グラフの役割分担と連携（絡み）

本課題では、**「理想的な数理モデル（Maxima）」**を、**「現実的な不均質環境（Python）」**に投影することで、実用的な炉の評価を行います。

| **グラフの種類**  | **担当ツール**  | **グラフが示すもの**                  | **連携における意味**                                              |
| ----------- | ---------- | ----------------------------- | --------------------------------------------------------- |
| **解析解グラフ**  | **Maxima** | 温度 $T$ に対する反応確率 $P$ の純粋な物理特性。 | **「理論上の型」の決定。** 特定の条件下で反応がどう動くべきかという「一意の正解」を確定させる。        |
| **統計分布グラフ** | **Python** | 炉内の全地点における反応成功率のばらつき（ヒストグラム）。 | **「実運用での再現性」の可視化。** 理論解を数千個のデータ点に適用し、炉全体の出力安定性（堅牢性）を算出する。 |

## 2. 物理的な意味と単位

- **Maximaでの検証**: $P(T) = \exp(-E_b / (kTS))$ という式が、高温になるほど指数関数的に立ち上がることを確認します。これにより「何度まで加熱すれば反応が始まるか」という**設計基準**が決まります。

- **Pythonでの検証**: 実際には炉の中は一定温度ではありません。Python側で「設定温度 $\pm 50K$」といった**温度ムラ（堅牢性への試練）**を引数として与え、その結果、どれだけの箇所で反応が起きているか（再現性）を確率分布として出力します。

## 課題レポート仕様書 (readme.md)

# 課題25：LENR炉の再現性と堅牢性の比較解析

## 1. 物理モデル

Ni-H（ニッケル・水素）系LENRの反応確率 $P$ を以下の通り定義する。

$P(T) = \exp\left( -\frac{E_b}{k T S} \right)$

- $E_b$: クーロン障壁 [eV]

- $k$: ボルツマン定数 [$eV/K$]

- $S$: 電子遮蔽係数

## 2. ツール間連成のロジック

1. **Maxima（理論構築）**:
   
   - トンネル効果に基づく反応確率式を一意に導出。
   
   - `plot2d` により、理論上の温度感度（一意解）をグラフ化し、物理的妥当性を検証する。
   
   - 解析式を `solution_p.txt` に出力。

2. **Python（統計的シミュレーション）**:
   
   - Maximaの解析式をインポート。
   
   - 炉内の「不均一な温度分布」を配列として生成し、全地点の反応確率を一括計算。
   
   - 反応成功率のヒストグラムを描画し、炉全体の「再現性」と「堅牢性」を定量評価する。

## 3. 単位系

- **温度 ($T$)**: $K$ (ケルビン)

- **エネルギー ($E_b$)**: $eV$ (電子ボルト)

- **確率 ($P$)**: $0.0 \sim 1.0$ (無次元)

## 4. 実行手順

1. `maxima -b task25.mac` : 理論解の抽出と検証グラフ表示。

2. `python task25.py` : 統計的配列処理と再現性分布の表示。

## 3. readme.md への補足（物理的解釈の修正）

> 【注意：実証に関する注記】
> 
> 本解析における「地球」の結果は、理想的なラボ環境において温度制御が完璧に行われた場合の「理論的上限」を示している。現実の地球上での再現性は、材料工学的な制約（遮蔽係数 $S$ の不安定性）により、依然として極めて低い。
> 
> 【堅牢性の定義】
> 
> この対比の主眼は、金星のような過酷な環境（高温・高圧）下では、仮に完璧な燃料（ナノ材料）を開発できたとしても、「環境による熱的ノイズ」だけでシステムが容易に崩壊するという、工学的な「炉としての堅牢性（Robustness）」の欠如を証明することにある。

### 欄外：連成エラー（SyntaxError）の回避について

> Maximaが出力する `%e` (ネイティブ指数記号) は、Pythonの `eval()` では解釈できないため、Python側で `replace("%e**", "np.exp")` を行うことで、NumPyの配列演算（ベクトル化）を可能にしている。これにより、1,000点以上の繰り返し計算を高速に処理し、炉全体の堅牢性評価を実現した。
