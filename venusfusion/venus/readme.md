# 課題28：金星大気からの炭素(CNT)資源抽出シミュレーション

## 1. 物理モデルの概要

金星の $CO_2$ 大気に水素を添加し、ボッシュ反応（$CO_2 + 2H_2 \rightleftharpoons C(s) + 2H_2O$）を用いて固体炭素（カーボンナノチューブ原料等）を抽出するプロセスの高度依存性を解析する。

## 2. 理論解の導出 (Maxima)

熱力学データを用いて、温度 $T$ に依存する平衡定数 $K(T)$ を算出する。

- **エンタルピー変化 ($\Delta H$):** $-178,000$ J/mol

- **エントロピー変化 ($\Delta S$):** $-160$ J/mol·K

- **平衡定数:** $K(T) = \exp\left( -\frac{\Delta H - T\Delta S}{RT} \right)$

## 3. 連成の技術的ノウハウ (Lesson Learned)

今回の連成において、バッチ処理と大容量データ転送を成功させるための重要なポイントは以下の3点である。

### ① ディレクトリの自動同期

バッチモード (`maxima -b`) では、GUIと異なり相対パスの解釈が厳格である。`load_pathname` が取得できる環境ではそれを使い、取得できないバッチ環境下でも `file_search_maxima(".")[1]` 等を用いて「実行ディレクトリ = 書き出しディレクトリ」を強制一致させることが不可欠である。

### ② display2d によるタグ排除

wXmaxima等のGUI環境では、出力にXMLタグ（`<math>`）が自動挿入される。これを放置すると Python の `np.loadtxt` がエラーを起こすため、ファイル出力時のみ `display2d: false` を設定し、純粋なテキストCSVとして書き出す必要がある。

### ③ 抽出ポテンシャルの単位と定義

本シミュレーションにおける Extraction Potential (抽出ポテンシャル) は以下の式で定義される。

$S(h) = \frac{K(T) \cdot P(h)}{1 + K(T)}$

- **単位:** $atm$ (相当値)

- **物理的意味:** 反応の平衡上の「右側（生成系）への偏り」と「環境圧力（衝突頻度）」の積であり、単位面積・単位時間あたりの理論的な最大回収ポテンシャルを示す指標。

## 4. 実行手順

1. **CLIにてデータ生成:** `maxima -b task28.mac` を実行。`equilibrium_data.txt` が生成される。

2. **Pythonにて解析:** `python task28.py` を実行。金星大気モデル（高度 0-60km）と理論解を連成。

## 5. 結果の解釈

シミュレーションの結果、抽出ポテンシャルは中高度（約20-40km）でピークを示す。これは、地表付近の「高温による平衡の不利」と、高高度の「低圧による反応密度の不足」のトレードオフが最適化される層がその高度に存在することを示唆している。

# 課題28：金星炭素資源抽出のシンボリック解析(sympy)

## 1. 物理モデル

ボッシュ反応（$CO_2 + 2H_2 \rightleftharpoons C(s) + 2H_2O$）による炭素回収を、金星の垂直大気構造（温度・圧力勾配）に基づいて解析。

## 2. 理論解 (SymPy / Analytical)

熱力学的諸定数から、温度 $T$ に依存する平衡定数 $K(T)$ を解析的に導出。

- $\Delta G(T) = -178,000 + 160T$
- $K(T) = \exp\left(-\frac{\Delta G(T)}{RT}\right)$

## 3. 数値シミュレーション (Python)

SymPyで定義した解析解を高速なNumPy演算へ変換し、大容量数値テーブルを介さずに直接高度プロファイルへ適用。

- **高度範囲:** $0 \sim 60$ km
- **抽出ポテンシャル:** $S(h) = \frac{K(T) P(h)}{1 + K(T)}$

## 4. 実行手順

1. Python環境にてスクリプトを実行。
2. SymPyによる解析解のLaTeX表示と、高度別の抽出効率グラフを同時に出力。
