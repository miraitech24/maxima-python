# 課題24：大気循環による排熱輸送の解析

## 1. 物理モデルの定義

金星等の惑星大気における、赤道から極への熱輸送を解析する。大気流速 $u$ を、緯度 $\phi$ に依存する以下の簡略化されたナビエ・ストークス方程式（定常・粘性・圧力勾配のバランス）から導出する。

### 支配方程式

$\frac{d^2u}{d\phi^2} = -A \cos(\phi)$

ここで、$u$ は緯度ごとの流速、$\phi$ は緯度（ラジアン）、$A$ は大気を駆動する圧力勾配係数である。

### 熱輸送モデル

$Q(\phi) = C \cdot u(\phi)$

排熱輸送量 $Q$ は流速に比例すると仮定し、係数 $C$ を用いて定式化する。

## 2. ツール間連成の役割と「絡み」

本課題では、数式処理の厳密性と数値データの柔軟性を両立させるため、以下の役割分担を行う。

| **役割分担**      | **ツール**    | **実施内容**                                                                                             |
| ------------- | ---------- | ---------------------------------------------------------------------------------------------------- |
| **数式処理・解析解**  | **Maxima** | 2階常微分方程式を解き、境界条件（赤道 $\phi=0$ で流速 $u=u_{max}$ かつ勾配 $du/d\phi=0$）を適用して**一意な解析解**を導出する。物理的妥当性をグラフで検証する。 |
| **配列処理・数値計算** | **Python** | Maximaが出力した「解の数式」をインポートし、NumPyを用いて緯度配列（180点以上）へ一括適用。繰り返し計算により、実運用に耐える数値データ群を生成する。                    |

## 3. 単位系

本解析では以下の単位系を標準として使用する。

- **緯度 ($\phi$)**: $rad$ （ラジアン） ※Python出力時は視覚化のため $deg$（度）に変換

- **流速 ($u$)**: $m/s$

- **熱輸送量 ($Q$)**: $W/m^2$ （単位面積あたりの熱流束）

- **物理定数 ($A, C$)**: 系を無次元化、または上記単位に準拠した比例定数

## 4. グラフの解釈

1. **Maximaグラフ**: 導出された関数 $Q(\phi)$ が、赤道で極大値を持ち、極に向かって滑らかに減少する物理現象を正しく記述できているかを確認するための「理論の型」である。

2. **Pythonグラフ**: 解析解という「型」に、任意の分割数やパラメータを流し込んだ「実数値」の集合である。これは将来的に他地点の観測データとの比較や、時系列処理を行うためのベースデータとなる。
