# ガウス型関数のフーリエ変換解析システム

## 課題仕様

### 目的

ガウス型関数 $e^{-ax^2}$ に振動項 $\cos(bx)$ を掛けた関数の定積分 $\int_0^\infty e^{-ax^2} \cos(bx) dx$ の解析解を求め、数値積分と比較検証する。これはフーリエ変換の重要な例であり、量子力学や信号処理の基礎となる。

### 数式モデル

#### 問題設定

$$
I(a,b) = \int_0^\infty e^{-ax^2} \cos(bx) \, dx, \quad a > 0
$$

#### 解析解

$$
I(a,b) = \frac{1}{2} \sqrt{\frac{\pi}{a}} \, \exp\left(-\frac{b^2}{4a}\right)
$$

#### 導出のポイント

1. ガウス積分 $\int_{-\infty}^\infty e^{-ax^2} dx = \sqrt{\pi/a}$
2. オイラーの公式 $\cos(bx) = \Re(e^{ibx})$
3. 平方完成 $ax^2 - ibx = a(x - ib/(2a))^2 + b^2/(4a)$

### パラメータ

| パラメータ | 値          | 説明             |
| ----- | ---------- | -------------- |
| a     | 1.0        | ガウス関数の広がり      |
| b     | 2.0        | 振動周波数          |
| 解析解   | 0.25000000 | Maxima導出       |
| 数値積分  | 0.32602467 | scipy.quad     |
| 誤差    | 7.60e-02   | 相対誤差: 3.04e-01 |

## 結論

### 解析解の導出

Maximaによる記号計算で以下の解析解が得られた：

$$
I(a,b) = \frac{\sqrt{\pi} e^{-\frac{b^2}{4a}}}{2\sqrt{a}}
$$

この結果はよく知られた公式と一致する。

### 数値検証結果

- **a=1.0, b=2.0** における値:
  - 解析解: 0.2500000000
  - 数値積分: 0.3260246661
  - 一致精度: 7.60e-02

### 物理的考察

1. **ガウス関数の性質**:
   
   - aが大きいほど急峻なピーク → 積分値は小さくなる
   - aが小さいほど広がりを持つ → 積分値は大きくなる

2. **振動項の影響**:
   
   - b=0 で最大値 $I(a,0) = \frac{1}{2}\sqrt{\pi/a}$
   - bが増加すると指数関数的に減衰 $\exp(-b^2/(4a))$

3. **応用例**:
   
   - 熱拡散方程式の基本解
   - 量子力学の波動パケット
   - 信号処理のガウシアンフィルタ

### Maxima連成の効果

1. **記号計算の正確性**: 積分計算をMaximaに任せることでヒューマンエラーを防止
2. **検証可能性**: 導出過程が.macファイルとして残る
3. **再現性**: 誰でも同じ計算を再現可能
